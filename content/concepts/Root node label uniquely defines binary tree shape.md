The label assigned to the [[concepts/root node|root node]] of a [[concepts/binary tree|binary tree]] uniquely determines the [[concepts/tree shape|tree shape]]. This property arises because [[concepts/tree isomorphism|tree isomorphism]] algorithms rely on similar [[concepts/node labeling|node labeling]] schemes, ensuring a [[concepts/bijective mapping|bijective mapping]] between positive integers and unique tree shapes where each tree shape corresponds to exactly one integer label and vice versa. [@colijn_metric_2018]

## Synthesis
The related concepts collectively establish that a systematic [[concepts/node labeling|node labeling]] scheme can uniquely characterize [[concepts/binary tree|binary tree]] topology through the label assigned to the [[concepts/root node|root node]], creating a [[concepts/bijective mapping|bijective mapping]] between labels and tree shapes that enables formal comparison via [[concepts/tree isomorphism|tree isomorphism]]. This labeling framework provides the mechanistic foundation for metrics that quantify distances between tree shapes, where similarity is determined by the extent to which trees share identically-labeled subtrees, allowing the [[concepts/metric|metric]] to effectively group trees generated by the same stochastic evolutionary process while distinguishing those from different processes. The approach proves particularly powerful because different generative [[concepts/models|models]]—including birth-death processes, Yule models, and Aldous models—leave distinctive topological signatures encoded in structural features like [[concepts/tree asymmetry|tree asymmetry]] and [[concepts/cherry|cherry]] frequency, which the [[concepts/node label|node-label]]-based metric can detect more effectively than simpler [[concepts/summary statistics|summary statistics]] like [[concepts/tree imbalance|tree imbalance]] alone. However, the sources do not fully resolve how sensitive this labeling approach is to different tree characteristics or whether certain evolutionary scenarios might produce convergent topological patterns that confound discrimination between generative processes.
