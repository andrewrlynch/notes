title: Multiscale BAF smoothing improves CNV call assignment accuracy
type: concept
---

CaSpER smooths the BAF shift signal using M-level multiscale decomposition with increasing window lengths between consecutive scales. This multiscale approach to BAF signal processing allows for better integration with the HMM-assigned copy number states to generate final CNV calls with improved [[concepts/accuracy|accuracy]].
