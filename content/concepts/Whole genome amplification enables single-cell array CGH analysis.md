Genome-wide [[concepts/aneuploid|aneuploidaneuploidy]] screening of a single cell can be performed by comparative genomic hybridization following whole genome amplification using degenerated oligonucleotide primed PCR or linker-adaptor PCR methods. This amplification strategy generates sufficient DNA from a single cell to enable subsequent [[concepts/chromosomal imbalance|chromosomal imbalance]] detection via array CGH. [@le_caignec_single-cell_2006]
