title: BAF generation from RNA-seq reads does not require prior variant calls
type: concept

CaSpER generates the BAF shift signal directly from mapped RNA-seq reads using an optimized BAF generation algorithm that does not rely on an existing set of variant calls. This approach considerably speeds up the process of estimating the BAF signal compared to methods that depend on pre-existing variant information. [@serin_harmanci_casper_2020]
