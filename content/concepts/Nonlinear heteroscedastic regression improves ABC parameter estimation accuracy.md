The [[concepts/approximate bayesian computation (abc)|abc]] package implements [[concepts/nonlinear heteroscedastic regression|nonlinear heteroscedastic regression]] methods for ABC to improve [[concepts/parameter estimation|parameter estimation]]. These methods enhance the [[concepts/accuracy|accuracy]] of ABC [[concepts/parameter estimation|parameter estimationestimates]], which can be further validated using [[concepts/cross validation|cross-validation]] tools to measure estimate accuracy.
